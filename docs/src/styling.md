# CSS Styling

For an optimal rendering of the bibliography, `DocumenterCitations` ships with a stylesheet [`citations.css`](https://github.com/JuliaDocs/DocumenterCitations.jl/blob/master/assets/citations.css) containing

~~~@eval
using Markdown
using DocumenterCitations
css_file = joinpath(DocumenterCitations.ASSETS_FOLDER, "citations.css")
if isfile(css_file)
    Markdown.parse("""
    ```css
    $(read(css_file, String))
    ```
    """)
end
~~~

This stylesheet is inserted automatically (by the [`DocumenterCitations.InjectAssets`](@ref) pipeline step) for any documentation that uses the [`CitationBibliography`](@ref) plugin. No `assets` entry in [`makedocs`](https://documenter.juliadocs.org/stable/lib/public/#Documenter.makedocs) is required.

The HTML generated by `DocumenterCitations` also uses CSS classes `canonical` and `noncanonical` to distinguish between [canonical](@ref canonical) and [non-canonical](@ref noncanonical) blocks. While these are not used in the above `citations.css`, custom CSS could implement different formatting for the two types of bibliographies.

To adapt or override the default styling, place a file `citations.css` (or any other name) in the `docs/src/assets` folder of your project, and list it as an `asset` for `Documenter.HTML` in your `docs/make.jl`:

```julia
makedocs(;
    format = Documenter.HTML(
        # ...
        assets=String["assets/citations.css"],
    ),
    plugins=[bib],
    # ...
)
```

Since the bundled stylesheet is inserted *before* any user-defined assets, the rules in such a file take precedence over the default styling.
